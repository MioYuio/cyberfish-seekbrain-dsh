# CyberFish SeekBrain — Neuroscience for DSH

一个模型配置，整套神经科学研究能力。

## 内容

- 68 个 SeekBrain 0.1.4 原始分析配方及参考。
- DSH 内的研究规划、配方检索与证据审计。
- 可选 DSH spawn 审计子 Agent，默认关闭。
- 通过 DSH 原生 MCP 使用 CopilotJ/Fiji。

## 不重复配置

不读取或保存独立 LLM Key，不携带 SeekBrain CLI/Pi/Node，不创建第二套模型供应商。DSH 当前模型、凭据、文件工具与审批始终由宿主管理。

## 图像控制

按需安装固定官方 CopilotJ Bridge 1.1.0，SHA-256 校验；Fiji-Latest / Java 17+ 开启 `127.0.0.1:3001/mcp`。不强制安装，不影响其它研究技能。安装后仍需人工复核图像与结果。

## 科学边界

`unverified` 不等于通过；可运行不等于有效。技能与预审不替代原始数据、代码、统计及实验设计审查。
